# Отчёт по ручной установке Arch Linux

## Цель работы

Выполнить ручную установку операционной системы Arch Linux с настройкой разделов диска, установкой базовой системы, загрузчика GRUB, сетевых служб и графического окружения GNOME.

---

# Ход работы

## 1. Проверка сетевого подключения

Для проверки доступа к сети была выполнена команда:

```bash
ping archlinux.org
```

Назначение:
- проверка подключения к интернету;
- проверка доступности DNS.

---

## 2. Проверка IP-адреса

Для определения IP-адреса системы использовалась команда:

```bash
ip addr show
```

Назначение:
- просмотр сетевых интерфейсов;
- получение IP-адреса для возможного подключения по SSH.

---

## 3. Синхронизация времени

```bash
timedatectl
```

Назначение:
- синхронизация системного времени;
- проверка состояния службы времени.

---

## 4. Просмотр доступных дисков

```bash
fdisk -l
```

Назначение:
- просмотр подключённых накопителей;
- определение имени диска для установки системы.

---

# Разметка диска

Для разметки выбран диск:

```bash
fdisk /dev/sdx
```

Внутри `fdisk` были выполнены следующие действия:

## Создание swap-раздела

```bash
n
p

+2G
```

## Создание системного раздела

```bash

```

## Изменение типа swap-раздела

```bash
t
1

```

## Проверка разметки

```bash
p
```

## Сохранение изменений

```bash
w
```

---

# Форматирование разделов

## Форматирование системного раздела

```bash
mkfs.ext4 /dev/sda2
```

## Форматирование swap-раздела

```bash
mkswap /dev/sda1
```

---

# Монтирование разделов

## Монтирование системного раздела

```bash
mount /dev/sda2 /mnt
```

## Активация swap

```bash
swapon /dev/sda1
```

---

# Установка базовой системы

```bash
pacstrap -K /mnt base linux linux-firmware sudo micro
```

---

# Создание файла fstab

```bash
genfstab -U /mnt >> /mnt/etc/fstab
```

---

# Переход в установленную систему

```bash
arch-chroot /mnt
```

---

# Настройка времени

## Установка часового пояса

```bash
ln -sf /usr/share/zoneinfo/Russia/Moscow /etc/localtime
```

## Синхронизация аппаратных часов

```bash
hwclock --systohc
```

---

# Установка необходимых пакетов

```bash
pacman -S dhcpcd iwd networkmanager grub gnome
```

---

# Настройка локализации

## Генерация локалей

```bash
locale-gen
```

## Установка языка системы

```bash
echo "LANG=en_US.UTF-8" > /etc/locale.conf
```

# Настройка имени хоста

```bash
echo archlinux > /etc/hostname
```

---

# Создание initramfs

```bash
mkinitcpio -P
```

---

# Установка пароля root

```bash
passwd
```

---

# Установка загрузчика GRUB

## Установка загрузчика

```bash
grub-install --target=i386-pc /dev/sda
```

## Генерация конфигурации GRUB

```bash
grub-mkconfig -o /boot/grub/grub.cfg
```

---

# Включение системных служб

## DHCP-клиент

```bash
systemctl enable dhcpcd
```

## NetworkManager

```bash
systemctl enable NetworkManager
```

## Wi‑Fi служба

```bash
systemctl enable iwd
```

## Графический менеджер входа

```bash
systemctl enable gdm
```

## SSH-служба

```bash
systemctl enable sshd
```

---

# Создание пользователя

## Создание нового пользователя

```bash
useradd -m username
```

## Установка пароля пользователя

```bash
passwd username
```

## Добавление пользователя в группы

```bash
usermod -aG wheel,audio,video,optical,storage,input username
```

---

# Настройка sudo

Открытие файла:

```bash
micro /etc/sudoers
```

Необходимо раскомментировать строку:

```bash
# %wheel ALL=(ALL:ALL) ALL
```

После изменения:

```bash
%wheel ALL=(ALL:ALL) ALL
```

---

# Завершение установки

## Выход из chroot

```bash
exit
```

## Размонтирование разделов

```bash
unmount -R /mnt
```

## Перезагрузка системы

```bash
reboot
```
